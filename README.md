# WIRE ESCAPE

手首のワイヤーで運河の街を飛び回り、走って追ってくる警官とヘリから3分逃げ切る3Dアクション。BREAK THE ROUTE（警察と犯人のカーチェイス）を土台に、犯人の車を「ワイヤーで飛ぶ人」に置き換えた（2026-10-30）。元の README は `docs/README-break-the-route.md`。

- 遊ぶ: https://tom3games.github.io/wire-escape/ （PC もスマホも。オフライン）
- 物語: 汚職警官の裏帳簿を盗んだ運び屋「カラス」。3分逃げ切るか、記者の待つ隠れ家へ

## 遊び方

| | |
|---|---|
| 勝ち | 3分逃げ切る。または90秒後に開く隠れ家（緑の光の柱）に、警察に見られずに入る |
| 負け | 警官に体を触れられ続ける（2.6m 以内・約0.9秒）。網・落とし穴・ダウン中に 6m まで寄られる |

- 警官は走って追う（2026-10-30 本人「車早すぎ。相手も人間が走ってきて」）。足は自分の 1.07〜1.19 倍、壁も登る（自分の 0.75 倍の速さ）。星3からワイヤーを使う警官も出る。サイレンは鳴らさない
- ワイヤー: 画面をタッチ（PC はクリック）した建物に掛かる（本人「画面タッチでワイヤー出して」）。大きいボタン / E キーは前の上へ自動（橙の輪の所）。振り子の一番下が地面から6m上に来る長さで張り、振り切ると自動で外れる。また掛ければ進み続けられる
- 巻き取り: ワイヤー中にスティックをワイヤーの方へ倒している間（PC は Shift を押している間）掛けた点へ加速し（最高 18m/s。本人「巻き取り早すぎ」で 32 から下げた）、手前で外れて前と上へ飛び出す（本人「スティックでワイヤーの方向向かうと巻き取り」）。ガスやゲージは無い（本人「ワイヤーとガスの両立はしないだろ」）
- 壁に向かって走ると駆け上がり、屋上に乗る
- 地面に着かずにワイヤーを6回つなぐと、警察が4秒見失う（次は20秒後から）
- 上から警官に飛び降りると踏みつけて倒す（4秒。手配度が1上がる）
- 車にはねられると体力が減る（時速25km以上の差）

### 警察の手（手配度＝星）

| 星 | 増えるもの |
|---|---|
| 2 | 捕獲ネット（警官が行き先を読んで撃つ。弾速22m/s・45m以内・見通しが通るとき・全体で6秒に1発まで。当たると2.6秒動けない。連打で早く抜ける）・拳銃（屋上にも届く。建物の陰なら当たらない。速く飛んでいると当たりにくい）・落とし穴（地上にいると行く手の道に黄色い予告の輪→1秒後に穴。落ちると2.2秒。ワイヤーですぐ出られる）・応援のパトカー |
| 3 | ヘリのミサイル（赤い円で予告。屋上の高さにも落ちる） |
| 4〜5 | 撃たれ続けると体力が0まで減って倒れる（3までは25%で止まる） |

一般車は元の0.55倍の速さ（本人「車早すぎ」）。

見た目と音はコミカルに（本人「SNS映え、ウケするコミカルな感じ」）: 通行人の裏声の悲鳴「キャーーッ！」と吹き出し、警官の「待てーっ！」、踏まれた警官の「ぐえっ」、通報の「もしもし警察!?」など。

救護所（地図の青い四角）で3秒止まると体力が全回復（警察に見られていると使えない。使うと手配度が下がる）。

## 迫力の演出（2026-11-03 空中しっぽ取り v5 から移植。本人「迫力がいい、爽快感がある」）

- 速さの線（canvas #speedfx、20m/s から速いほど多く濃く）。CSS の流れる線は車のニトロだけに残した
- 視野は速いほど広く（最大+18度）＋速く離した瞬間に一瞬広がる（fovKick）。振り子の向きに少し傾く（最大0.1rad、カメラの右向きから横速度を取る）
- 風の環境音を録音のループにして速さで大きく（ノイズ合成をやめた。2026-11-03 に air_01 から wind_loop.wav へ）。速く手で離すと録音の whoosh
- 山場で一瞬止める＋画面のふちの光（#hitflash）＋揺れ: 警察が見失った 0.12秒・踏みつけ 0.1秒・ネットを抜けた 0.05秒・穴から出た 0.04秒
- ワイヤー中だけ重力1.07倍・最高速 38→41（逃げる側だけ。警官は 38 のまま）。CPU 128 回で逃げ切り 58%→57%（両方に掛けると 52% に落ちたので警官は外した）
- 確認: `node tools/wire-juice.mjs [webkit]`（22項目、shots/juice/wire-*）
- キャッシュバスター: public の js/shared の import と tools/test/lib の import に全部 `?v=N` が付いている。上げる時は `grep -rl "?v=9'" public tools test lib | xargs sed -i '' "s/?v=9'/?v=10'/g"` と index.html の3か所（style.css・modulepreload・main.js）

## 地面ワイヤー（2026-11-03、?v=8）

- 本人「空中に浮いてる間は地面にもワイヤーつけて加速できるように」「地面をちゃんとタップしなあかん感じに」。共通仕様は claude-config の feedback-wire-game-controls.md「地面ワイヤー」
- 空中（立っていない・壁に張り付いていない）で、画面の道・屋上をタップした時だけ。ワイヤーボタン・E キー・自動の狙いでは掛からない。建物の当たりが地面の当たりより 6m 以内なら建物（屋上の面は地面扱い）。判定は runner.js の aimTap
- 掛けた瞬間に点の向きへ +9m/s（groundWireBoost）、その後 groundWireAcc 48 で加速（最高速 41 で止まる。25m/s まで約0.1〜0.2秒）。点から 4m・点を通り過ぎた・足元 1m 以内で下りている・3秒、のどれかで外れる。足元から 3m より上で外れた時だけ進む向きに +4・上へ 3.5 以上、床の近くで外れた・ロープのまま着地した時は跳ねずにそのまま着地（2026-11-03 本人「あんまり加速できない」「着いてからバウンドするのはおかしい」）。外れる時は風切りと視野の広がり。つなぎの回数（見失わせ）には数えない
- 犯人だけ。警官（role cop）は掛からない。CPU の警官は狙いの点を使わない。オンラインのサーバー（lib/）は車だけで人の動きを判定しないので、地面ワイヤーは関係しない
- 確認: `node tools/runner-test.mjs`（地面ワイヤー7項目）、`node tools/groundwire-num.mjs`（25m/s までの秒・最高速・外れた後に上がる高さ）、`node tools/groundwire.mjs [webkit]`（実ブラウザでタップ、shots/groundwire/）、`node tools/sim-runner.mjs 48 5 botg`（地面ワイヤーも使う CPU）

## ロード画面と音（2026-11-03）

- 開いた最初は「警察無線を傍受しています」のロード画面（index.html の #loader。HTML/CSS/SVG だけ）。回転灯の光が回り、周波数の針が本物の読み込みで進む: 起動スクリプト45本で40%、街の素材（THREE の読み込み係が数えるテクスチャ・空・壁）で55%、最初のコマで残り。全部読み終えて2コマ後に消える。車のモデル（1.5MB）は消えてから読む（それまで手続きの車）
- スクリプトが読めない・起動前のエラー・30秒まったく進まない、のどれかで「無線が途切れました」と原因・もう一度ボタン
- import を足したら index.html の `jsTotal` を直す（`node tools/loader-test.mjs [webkit]` が数の食い違いを見つける）
- 読み込みの速さ: `node tools/loadtime.mjs [URL|local]`（Fast 3G 相当）
- 風: 本人「謎の水の音がずっと鳴ってる」。air_01（2.6秒の一発の音）をループしていて2.6秒ごとに水のようなシューが鳴り、走るだけ（6m/s）で鳴っていた。録音のループ snd/wind_loop.wav（Howling wind・CC0・WAV のまま）に替え、地面では 0、空中で min(0.35, (v-16)/40)

## 操作

| PC | スマホ | 動作 |
|---|---|---|
| W A S D / 矢印 | 左手のスティック（触った所に出る。倒した向きへ走る） | 走る・向き / スイング中は前へこぐ |
| Space | ジャンプ | ジャンプ（ネット・穴では連打） |
| クリック | 建物をタッチ | その建物へワイヤー。もう一度で外す |
| E / K | 大きい橙のボタン | 前の上へ自動でワイヤー |
| Shift / Q（押している間） | スティックをワイヤーの方へ倒す | 巻き取り |
| X / Ctrl | 目のボタン | しゃがみ歩き（隠密） |
| マウスでなぞる | 画面をなぞる | カメラを回す（スマホは自分で回す。PC は1.5秒で後ろへ戻る） |
| R / Esc / C / M | 上のボタン | 戻る / ポーズ / カメラの距離 / 音 |

## 作り

- `public/shared/runner.js` 人の動き（three.js 非依存）。走る・跳ぶ・壁登り・ワイヤーの振り子・巻き取り・車との当たり・ネットと穴の状態
- `public/shared/runnerbot.js` CPU のワイヤーの人（タイトルのデモと釣り合いの測定）
- `public/shared/chase.js` 警察と犯人の判定（BREAK THE ROUTE のものに、人の逮捕の高さ判定・捕獲ネット・落とし穴・踏みつけ・見失いを足した）
- `public/js/runnermodel.js` 人の見た目（手続きのローポリ、関節を回して動かす）
- 調整値: `RUN`（runner.js）と `CHASE`（config.js）
- オンライン対戦のサーバー（server.mjs・lib/）は元のまま残っているが、画面からは外した

## 検証

```
node tools/runner-test.mjs          # 走る・跳ぶ・ワイヤー・巻き取り・壁登り・運河（描画なし）
node tools/sim-runner.mjs 16 5 bot  # CPU のワイヤーの人と警察5台を16回。勝ち負けとネット・穴・弾の数
node tools/sim-runner.mjs 4 5 still # 何もしない人はすぐ捕まるか
node tools/play.mjs [webkit]        # 実ブラウザで通し（スクショは shots/play/）
node tools/mobile-we.mjs            # iPhone 相当 6 サイズ（タイトル一画面・タッチで走る/ワイヤー/巻き取り・重なり）
node tools/og.mjs                   # OGP 画像
```

CPU のワイヤーの人と警察5台（2026-10-30・16回）: 逃げ切り9・逮捕7。
