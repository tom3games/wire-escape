# WIRE ESCAPE

手首のワイヤーで運河の街を飛び回り、パトカーとヘリから3分逃げ切る3Dアクション。BREAK THE ROUTE（警察と犯人のカーチェイス）を土台に、犯人の車を「ワイヤーで飛ぶ人」に置き換えた（2026-10-30）。元の README は `docs/README-break-the-route.md`。

- 遊ぶ: https://tom3games.github.io/wire-escape/ （PC もスマホも。オフライン）
- 物語: 汚職警官の裏帳簿を盗んだ運び屋「カラス」。3分逃げ切るか、記者の待つ隠れ家へ

## 遊び方

| | |
|---|---|
| 勝ち | 3分逃げ切る。または90秒後に開く隠れ家（緑の光の柱）に、警察に見られずに入る |
| 負け | 地上で警察の車に囲まれて遅くなる（逮捕ゲージ約2秒）。体力が尽きて倒れたとき、近く（25m）の地上に警察がいる |

- 屋上と空中では逮捕されない（警察の車と高さが4m以上離れていればゲージはたまらない）
- ワイヤー: 前の上の建物に掛かる（橙の輪が掛かる場所）。振り子の一番下が地面から6m上に来る長さで張り、振り切ると自動で外れる。また掛ければ進み続けられる
- 巻き取り: ワイヤー中に押すと掛けた点へ一気に飛び、手前で外れて前と上へ飛び出す（1.2秒に1回）。ガスやゲージは無い（本人「ワイヤーとガスの両立はしないだろ」）
- 壁に向かって走ると駆け上がり、屋上に乗る
- 地面に着かずにワイヤーを6回つなぐと、警察が4秒見失う（次は20秒後から）
- 高い所から警察の車に落ちると踏みつけて止める（パトカーは燃えて離れた所から戻る。手配度が1上がる）
- 車にはねられると体力が減る（時速25km以上の差）

### 警察の手（手配度＝星）

| 星 | 増えるもの |
|---|---|
| 1 | 捕獲ネット（パトカーが行き先を読んで撃つ。弾速30m/s・38m以内・見通しが通るとき。当たると2.6秒動けない。ジャンプかワイヤーの連打で早く抜ける） |
| 2 | 拳銃（屋上にも届く。建物の陰なら当たらない。速く飛んでいると当たりにくい）・落とし穴（地上にいると行く手の道に黄色い予告の輪→1秒後に穴。落ちると2.2秒。ワイヤーですぐ出られる）・応援のパトカー |
| 3 | ヘリのミサイル（赤い円で予告。屋上の高さにも落ちる） |
| 4〜5 | 撃たれ続けると体力が0まで減って倒れる（3までは25%で止まる） |

救護所（地図の青い四角）で3秒止まると体力が全回復（警察に見られていると使えない。使うと手配度が下がる）。

## 作り

- `public/shared/runner.js` 人の動き（three.js 非依存）。走る・跳ぶ・壁登り・ワイヤーの振り子・巻き取り・車との当たり・ネットと穴の状態
- `public/shared/runnerbot.js` CPU のワイヤーの人（タイトルのデモと釣り合いの測定）
- `public/shared/chase.js` 警察と犯人の判定（BREAK THE ROUTE のものに、人の逮捕の高さ判定・捕獲ネット・落とし穴・踏みつけ・見失いを足した）
- `public/js/runnermodel.js` 人の見た目（手続きのローポリ、関節を回して動かす）
- 調整値: `RUN`（runner.js）と `CHASE`（config.js）
- オンライン対戦のサーバー（server.mjs・lib/）は元のまま残っているが、画面からは外した

## 検証

```
node tools/runner-test.mjs          # 走る・跳ぶ・ワイヤー・巻き取り・壁登り・運河（描画なし）
node tools/sim-runner.mjs 16 5 bot  # CPU のワイヤーの人と警察5台を16回。勝ち負けとネット・穴・弾の数
node tools/sim-runner.mjs 4 5 still # 何もしない人はすぐ捕まるか
node tools/play.mjs [webkit]        # 実ブラウザで通し（スクショは shots/play/）
node tools/mobile-we.mjs            # iPhone 相当 6 サイズ（タイトル一画面・タッチで走る/ワイヤー/巻き取り・重なり）
node tools/og.mjs                   # OGP 画像
```

CPU のワイヤーの人と警察5台（2026-10-30・16回）: 逃げ切り9・逮捕7。
